# Fatal-Identity-Missing
A terminal website where you find yourself while trying to convince a machine that you exist.

![Intro screen](screenshot1.png)


## [Demo](https://fatal-identity-missing.vercel.app)

## How to play 

1. Type your name when the machine sks you to identify yourself.
2. Watch the registry scan come back with nothing.
3. Choose how to respond to the machine's questions.
4. Survive the silence at the end.

Your name is saved in your browser, so the machine will remember you on your next visit.

## Features

- Typing-effect terminal interface with a fake registry scan.
- Identity choice with rejections that escalate until only one option remains.
- Webgl torch light that follows your mouse.
- "Who am i" Build-up with a dread audio track and a burgundy veil
- Final logo after a silence

## Tech Stack

- HTML, CSS , and JavaScript
- WebGL
- local storage for remembering your name
- web audio api for ambient hum and keystroke sounds.

## Running it locally 

- clone or download this repositary.
- Open the folder in VS Code.
- Install the **Live Server** extension.
- Right-click `index.html` and choose **Open with live Server**.

Click the page once before starting so the audio can play.
